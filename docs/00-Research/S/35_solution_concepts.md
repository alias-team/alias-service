# C1 계열 — Journey-Fit Judgment

## Solution S1-A. 게이트 방향이 제품 옆의 문장을 바꾼다

| 항목 | 내용 |
| --- | --- |
| **Problem Moment** | 면세 매장 진열대 앞. 고객은 아무것도 입력하지 않았고 직원과도 말하지 않았다 |
| **Trigger** | 고객이 특정 매대 구역에 머문다. 그 구역이 속한 터미널 존의 **탑승 게이트 방향 정보**(공개 운항 정보)가 입력된다 |
| **Core AI Decision** | AI가 **그 방향으로 가는 여정의 전형적 장면과 이 제품의 관계**를 판단한다 |
| **Experience** | 제품 옆 작은 표면의 문장이 시간대에 따라 바뀐다. 동남아 노선 시간대에는 습도와 소재, 유럽 장거리 시간대에는 기내 수납과 무게에 관한 한 문장 |
| **Before** | 모든 고객이 같은 제품 태그(소재·가격)를 본다 |
| **After** | 지금 이 게이트로 가는 사람들에게 유효한 한 문장이 제품 옆에 있다 |
| **Why AI** | 취항 노선 × 시간대 × 제품 조합이 수만이며 **사전 제작 불가**. 직원이 전 세계 목적지를 알 수 없다 [`34` DEC-01] |
| **Why MCM** | 1976년 뮌헨 여행 제품에서 출발한 브랜드가 **여행 맥락에서 제품을 말하는 것**은 헤리티지의 직접 사용이다 [A급 공식] |
| **Customer Engagement** | 브랜드가 고객의 상황을 먼저 알고 있다는 인상. 고객은 아무것도 하지 않았다 |
| **Conversion** | 제품 스펙이 아니라 **자기 여정의 장면**으로 제시돼 확신이 형성될 수 있다 (Hypothesis) |
| **LTV** | 🔴 **약하다.** 그 자리에서 끝난다. C3 계열과 결합하지 않으면 일회성 |
| **Luxury** | 화면이 아니라 **제품 옆 작은 표면**. 고객이 조작하지 않고 기술이 드러나지 않는다 [QA-3-3, A급 공식 정합] |
| **Repeat Usage** | 🔴 **약하다.** 다음 여행 때 다시 오면 다른 문장이 있으나 고객이 그것을 기대하고 오지는 않는다 |
| **Standalone MVP** | 웹에서 "게이트 존 선택 → 시간대 → 제품" 입력 시 판단 결과가 나오는 화면. 운항 정보·제품 정보 더미 |
| **Clutch Moment** | 같은 제품 앞에서 **오전 방콕 노선 시간대와 저녁 파리 노선 시간대의 문장이 완전히 다르게** 바뀌는 장면 |

## Solution S1-B. 여정을 고르면 후보 제품들의 자리가 갈린다

| 항목 | 내용 |
| --- | --- |
| **Problem Moment** | 고객이 두세 개 제품 사이에서 결정하지 못하고 있다. 시간은 제한돼 있다 |
| **Trigger** | 고객이 목적지·기간을 3초 안에 고른다(도시 카드 선택). **탑승권 스캔 없음** |
| **Core AI Decision** | AI가 **각 후보 제품이 그 여정에서 차지하는 자리와 차지하지 못하는 자리**를 판단한다 |
| **Experience** | 후보 제품들이 "그 여정의 어느 장면에 있고 어느 장면에는 없는지"로 갈린다. 순위가 아니라 **자리**로 제시된다 |
| **Before** | 제품 비교가 가격·크기·색상 축으로만 이뤄진다 |
| **After** | "이 제품은 그 5일 중 이동일에, 저 제품은 도착 후 저녁에"처럼 **여정 위의 배치**로 비교된다 |
| **Why AI** | 목적지 × 기간 × 제품 조합 폭발. **순위 매기기가 아니라 장면 배치**이므로 정렬 로직으로 대체되지 않는다 |
| **Why MCM** | `Made for Movement`가 카피가 아니라 **판단의 기준**이 된다 [A급 공식] |
| **Customer Engagement** | 브랜드가 제품이 아니라 **고객의 여정**을 먼저 이해한 것처럼 작동 |
| **Conversion** | 🟢 **강하다.** 결정 순간에 직접 개입하며, 비교 축을 가격에서 여정으로 옮긴다 [가격 동기 26%→17% 하락과 정합, A/B급] |
| **LTV** | 🟡 중간. 선택 근거가 여정이면 그 여정 후 회상이 생길 수 있다 (Hypothesis) |
| **Luxury** | 할인·재고 압박이 없고 **비교를 가치 축으로 옮긴다** [MCM "높은 가격이 아닌 높은 가치", A급 공식] |
| **Repeat Usage** | 🟡 **중간.** 여정이 바뀔 때마다 답이 바뀌므로 다음 여행에서 다시 유효 |
| **Standalone MVP** | 도시·기간 선택 → 후보 제품 3개의 여정 위 배치 판정. 제품 정보는 공개 카탈로그, 목적지 정보는 더미 |
| **Clutch Moment** | 같은 세 제품이 **"도쿄 2박 출장"과 "발리 7일 휴가"에서 완전히 다른 자리로 재배치**되는 장면 |

## Solution S1-C. 여행이 끝나고 판단이 맞았는지 확인한다

| 항목 | 내용 |
| --- | --- |
| **Problem Moment** | 매장이 아니라 **여행 중·여행 후**. 고객은 면세에서 산 제품을 실제로 쓰고 있다 |
| **Trigger** | 매장에서 만들어진 여정 판단이 그 여정의 실제 시점에 도달한다 |
| **Core AI Decision** | AI가 **매장에서 내린 판단 중 어느 것이 실제 여정에서 검증 가능한 시점에 왔는지**를 판단한다 |
| **Experience** | "이 가방을 이동일에 쓰실 거라고 봤는데 어떠셨나요"처럼 **브랜드가 자기 판단을 되짚는다.** 고객의 답이 다음 판단을 고친다 |
| **Before** | 면세 구매는 그 자리에서 끝난다. 다음 연락은 신제품 알림이다 |
| **After** | 매장의 판단이 여정 안에서 확인되고, 브랜드가 그 고객을 조금 더 알게 된다 |
| **Why AI** | 여정마다 검증 시점이 다르다. **"구매 30일 후"는 이동 중인 고객에게 의미가 없다** [`34` DEC-05] |
| **Why MCM** | MCM이 지정한 **오프라인 → 온라인** 방향의 직접 실행 [QA-3-1, A급 공식] |
| **Customer Engagement** | 🟢 **강하다.** 브랜드가 자기 판단에 책임을 지고 되묻는다 |
| **Conversion** | 🔴 약하다. 구매 이후다 |
| **LTV** | 🟢 **강하다.** 판단 → 검증 → 개선의 축적이 다음 여정의 이유가 된다 |
| **Luxury** | 마케팅이 아니라 **어드바이저의 후속 확인**의 형태. 럭셔리 클라이언텔링 실무와 정합 [B급] |
| **Repeat Usage** | 🟢 **가장 강하다.** 여정마다 반복되고 축적된다 |
| **Standalone MVP** | 🟡 **시간 경과 시연이 어렵다.** 3주 안에는 시뮬레이션(타임라인 압축)으로만 가능 |
| **Clutch Moment** | 매장에서 내린 판단과 **여행 후 고객의 답이 나란히 놓이고, 다음 판단이 달라지는** 장면 |

# C2 계열 — Silent Signal Judgment

## Solution S2-A. 제품이 집어 든 사람에 따라 다르게 반응한다

| 항목 | 내용 |
| --- | --- |
| **Problem Moment** | 고객이 제품을 집어 들었다. 직원은 다른 고객을 응대 중이다 |
| **Trigger** | 제품을 집어 드는 행위 자체. **카메라가 아니라 제품 거치대의 무게·접촉 신호**(익명) |
| **Core AI Decision** | AI가 **① 지금 개입해도 되는가 ② 얼마나 깊게 ③ 무엇을 보일 것인가**를 동시에 판단한다 |
| **Experience** | 제품을 든 순간 옆 표면에 한 문장이 나타난다. 오래 들고 있으면 문장이 깊어지고, 곧 내려놓으면 아무것도 나타나지 않는다 |
| **Before** | 44~46%가 아무 개입 없이 나간다 [E5, Fact] |
| **After** | 직원이 도달하지 못한 고객에게도 개별 개입이 일어난다 |
| **Why AI** | 직원은 정의상 도달하지 못했고 **사이니지는 모두에게 같아 개별 개입이 아니다.** 신호 6개 이상을 몇 초 안에 통합 [`34` DEC-02] |
| **Why MCM** | 🟡 **약하다.** 판단 구조 자체는 브랜드 무관. **진입점 내용에 MCM 자산을 넣어야 특수성이 생긴다** |
| **Customer Engagement** | 🟢 **강하다.** MCM이 말한 "말을 걸어주거나" [QA-3-3, A급 공식]의 직접 실행 |
| **Conversion** | 🟢 **강하다.** 개입받은 사람의 76%가 결정에 영향 인정 [E4, Fact] |
| **LTV** | 🔴 약하다. 그 자리에서 끝난다 |
| **Luxury** | 🟡 **가장 조심해야 한다.** 무게·접촉 신호만 쓰고 **카메라를 쓰지 않는 것**이 성립 조건. 내려놓으면 사라지는 설계가 "감시받지 않는다"를 보장 |
| **Repeat Usage** | 🔴 약하다 |
| **Standalone MVP** | 웹에서 "집어 듦 → 유지 시간 → 내려놓음" 신호 시퀀스를 합성해 판정 로직 시연 |
| **Clutch Moment** | 같은 제품을 **3초 들었다 놓은 사람에게는 아무것도 나타나지 않고, 20초 들고 되돌아온 사람에게는 문장이 나타나는** 대비 |

## Solution S2-B. 직원에게 지금 누구에게 무슨 말을 할지 알려 준다

| 항목 | 내용 |
| --- | --- |
| **Problem Moment** | 피크 시간대. 매장에 5명 이상이 동시에 있고 직원은 한 명이다 |
| **Trigger** | 직원이 한 고객 응대를 마친 순간 |
| **Core AI Decision** | AI가 **지금 남은 익명 세션 중 개입의 한계효용이 가장 큰 대상과 그 사람에게 유효한 한마디**를 판단한다 |
| **Experience** | 직원의 손목·이어피스에 "왼쪽 세 번째 매대, 두 번째 방문, 트래블 라인"처럼 대상과 한마디가 온다. **고객은 이 시스템의 존재를 모른다** |
| **Before** | 직원이 눈에 띄는 고객 또는 먼저 말을 건 고객에게 간다 |
| **After** | 직원의 제한된 시간이 전환 차이가 가장 큰 곳에 배분된다 |
| **Why AI** | **직원 한 명이 5명 이상을 동시에 읽을 수 없다.** MCM이 지목한 규모 문제 [QA-4-3, A급 공식]의 직접 대응 |
| **Why MCM** | 🟡 **약하다.** 어느 브랜드 매장에나 적용된다 |
| **Customer Engagement** | 🟡 **간접.** 고객은 AI가 아니라 사람을 만난다 — 이것이 장점이자 한계 |
| **Conversion** | 🟢 강하다. 76%의 상호작용 영향력을 더 많은 고객에게 확장 [E4, Fact] |
| **LTV** | 🔴 약하다 |
| **Luxury** | 🟢 **가장 안전하다.** 인간 어드바이저를 대체하지 않고 증폭한다. 고객 앞에 기술이 드러나지 않는다 [Step 9 기준 전부 통과] |
| **Repeat Usage** | 🟡 직원이 매일 쓴다. 고객 반복 사용은 아니다 |
| **Standalone MVP** | 매장 평면 위 5개 익명 세션 시뮬레이션 → 우선순위 판정 + 한마디 생성 |
| **Clutch Moment** | 매장에 5명이 동시에 있을 때 **AI가 지목한 사람과 사람이 직관으로 고를 사람이 다르고, 그 이유가 화면에 근거로 제시되는** 장면 |

## Solution S2-C. AI가 지금은 말 걸지 않기로 판단한다

| 항목 | 내용 |
| --- | --- |
| **Problem Moment** | 고객이 매장을 둘러보고 있다. 개입이 도움이 될 수도, 방해가 될 수도 있다 |
| **Trigger** | 상시. 다만 **출력의 기본값이 "아무것도 하지 않음"**이다 |
| **Core AI Decision** | AI가 **개입해야 하는가 물러나야 하는가**를 먼저 판단하고, 물러나기로 하면 **나중에 쓸 흔적만** 남긴다 |
| **Experience** | 대부분의 시간 동안 아무 일도 일어나지 않는다. 고객이 같은 제품에 세 번째 되돌아온 순간에만 무언가가 나타난다 |
| **Before** | 매장 기술은 켜져 있으면 항상 말을 건다 |
| **After** | 브랜드가 **침묵을 선택하는 것 자체가 경험**이 된다 |
| **Why AI** | 🟡 **약하다.** "3회 되돌아오면 개입"은 룰로도 가능하다. **AI 필연성은 신호 조합이 복잡할 때만 생긴다** |
| **Why MCM** | 🟢 MCM의 **"고객이 생경하게 여기는 기술 중심 장치는 지양"** [QA-3-3, A급 공식]에 정면 대응 |
| **Customer Engagement** | 🟡 중간. 방해하지 않는 것은 관계 형성이 아니다 |
| **Conversion** | 🟡 중간. 잘못된 개입으로 인한 이탈을 막는다 |
| **LTV** | 🔴 약하다 |
| **Luxury** | 🟢 **가장 강하다.** Guardrail을 문제 정의에 내장했다 |
| **Repeat Usage** | 🔴 약하다 |
| **Standalone MVP** | 신호 시퀀스별 개입/비개입 판정과 그 근거 표시 |
| **Clutch Moment** | 10개 시나리오 중 **9개에서 AI가 아무것도 하지 않고 1개에서만 반응하는** 장면 |

# C3 계열 — Continuation Timing Judgment

## Solution S3-A. 제품이 실제로 쓰일 순간에 나타난다

| 항목 | 내용 |
| --- | --- |
| **Problem Moment** | 여행 3일 차. 고객이 면세에서 산 가방을 처음 제대로 쓰는 날 |
| **Trigger** | AI가 판단한 **제품의 첫 실사용 추정 시점** |
| **Core AI Decision** | AI가 **목적지·기간·제품에서 그 제품이 실제로 쓰일 첫 시점**을 판단한다 |
| **Experience** | 그 시점에 한 문장이 도착한다. 판매가 아니라 **사용에 관한 것** |
| **Before** | 구매 후 연락은 신제품 알림뿐이다 |
| **After** | 브랜드가 제품이 쓰이는 순간에 함께 있다 |
| **Why AI** | 🟡 **중간.** "구매 3일 후" 룰로 근사되나 목적지·기간·제품 조합에서 실사용 시점이 달라진다 |
| **Why MCM** | 🟡 중간. 여행 제품 라인 |
| **Customer Engagement** | 🟢 강하다 |
| **Conversion** | 🔴 없다 |
| **LTV** | 🟢 **강하다** |
| **Luxury** | 🟡 **조건부.** 판매 언급이 하나라도 들어가면 마케팅 알림으로 전락 |

## 이 문서의 한계

1. **9개 Solution 전부 고객 검증이 없다.** 각 Solution의 Customer Value는 `Hypothesis`다.
2. **S2 계열의 신호 수집 방식이 미해결이다.** 무게·접촉 센서를 가정했으나 실제 면세 매장에서 가능한지 미확인이다.

5. **Solution의 실현 가능성은 `36`에서 평가한다.** 이 문서는 발산만 수행했다.
