# 럭셔리 AI 현재 사례: 도입 단계·성과·전이 경계

> 조사 기준일: 2026-08-04. 이 문서는 MCM, 직접 경쟁사와 모기업, 선정 벤치마크 및 보완 사례의 공개 AI 근거를 같은 스키마로 기록한다. 파트너 고객 사례와 수상 제출의 성과 주장은 독립 감사 결과가 아니다. 공개 근거가 없는 브랜드별 범위·ROI·정확도·고객 반응은 `성과 비공개` 또는 `확인 불가`로 남긴다. 이 문서는 MCM 솔루션을 제안하거나 우선순위를 결정하지 않는다.

## 1. 세 분류축은 서로 다르다

Task 1에서 남은 용어 혼동을 해소하기 위해 다음 세 축을 명시적으로 분리한다.

| 분류축 | 답하는 질문 | 허용값 | 적용 위치 |
| --- | --- | --- | --- |
| **AI 배포 단계** | 해당 기능이 지금 어느 수준까지 실행됐는가? | `실제 도입`, `시범`, `캠페인`, `연구`, `계획` | 이 문서의 모든 사례 |
| **근거 분류·신뢰도** | 출처가 직접 지지하는 사실인가, 해석인가? 얼마나 믿을 수 있는가? | 출처 장부의 `사실`·`추론`·`가설`·`비공식 참고`와 `높음`·`중간`·`낮음` | 각 사례의 마지막 필드와 해석 표 |
| **미래 신호 분류** | 앞으로의 방향을 어떤 강도로 말할 수 있는가? | `공식 계획`, `강한 신호`, `산업 전망`, `연구자 추론` | [06_future_ai_directions.md](06_future_ai_directions.md) |

배포 단계의 의미는 다음과 같다. `실제 도입`은 명시된 사용자·업무에서 사용 중이라는 공개 근거가 있는 상태, `시범`은 프로토타입·파일럿·행사 공개처럼 범위가 제한된 실행, `캠페인`은 한시적 마케팅·콘텐츠 실행, `연구`는 실험·검증이지만 배포 의도가 확정되지 않은 상태, `계획`은 공식 탐색·개발·확장 의향만 공개된 상태다. 배포 단계가 높다고 성과가 검증된 것은 아니며, `실제 도입`도 성과 비공개일 수 있다.

## 2. 모든 사례에 적용하는 정확한 스키마

아래 18개 필드는 모든 사례에 같은 순서로 사용한다.

| 필드 | 기록 규칙 |
| --- | --- |
| 사례 ID | 문서 내 영구 ID `AI-##` |
| 브랜드·주체 | 브랜드, 모기업, 기술 파트너를 분리 표기 |
| 사례명 | 공개된 기능·프로그램명 |
| 날짜 | 공개 또는 근거 시점 |
| 영역 | 고객경험, 매장, 콘텐츠, 제품·디자인, 운영·공급망, 신뢰·보안 중 하나 이상 |
| 문제 | 출처가 직접 제시하거나 근거에서 제한적으로 읽히는 문제 |
| 여정·워크플로 | 입력부터 사람의 판단 또는 결과까지의 공개 흐름 |
| AI 기법 | 공개된 범위만 기록하고 모델을 추정하지 않음 |
| 고객/직원 사용자 | `고객`, `직원`, `고객+직원`으로 직접 사용자와 수혜자를 구분 |
| AI 배포 단계 | `실제 도입`, `시범`, `캠페인`, `연구`, `계획` 중 하나 |
| 확인된 성과 | 실행 사실과 출처가 보고한 결과를 구분. 파트너 보고는 그렇게 명시 |
| 비공개 성과 | 정확도·전환·매출·비용·만족도·현재 범위 등 공개되지 않은 항목 |
| 브랜드 영향 | 확인된 영향과 의도·해석을 분리 |
| 하이엔드 연결 | 공예·헤리티지·희소성·특별 대우·인간 서비스와의 접점 |
| 전이 원칙 | 사례에서 일반화할 수 있는 원칙이며 MCM 기능 제안은 아님 |
| MCM 제한 | MCM에 그대로 대입할 수 없는 데이터·규모·접근·브랜드 차이 |
| 출처 | 출처 장부의 영구 ID와 게시일 |
| 근거 분류·신뢰도 | AI 배포 단계와 별개로 `사실/추론` 및 신뢰도 기록 |

## 6. 현재 근거가 허용하는 결론

- **배포와 성과는 다르다.** AI-02·04·06·07·08·10은 `실제 도입`이지만, 독립 검증된 ROI를 공개한 사례는 이 조사 범위에서 확인되지 않았다.
- **하이엔드에 가까운 공개 패턴은 고객 접점의 완전 자동화보다 직원 증강에 가깝다.** LV는 장인·어드바이저의 최종 판단을 명시하고, Gucci와 Burberry는 각각 담당자 어조·Client Advisor 지원을 공개한다. Gucci 담당자의 수정·승인 절차는 확인 불가다. 현재 관찰은 IND-603·605·611·702가 지지하는 **사실·중간~높음**이며, 공통 방향이라는 결론은 **추론·중간**이다.
- **브랜드와 모기업·파트너를 섞지 않는다.** Mira는 Tapestry, 추천은 Prada Group, AI 영상은 Maison Meta 제작, Furla 보호 성과는 Crane의 고객 사례다. Coach·Prada·Tory Burch·Furla 자체 시스템이나 독립 검증 성과로 확대하지 않는다.
- **MCM의 공개 상태는 비대칭이다.** DPP는 실제지만 AI가 아니고, AI 수요예측은 `계획`이다. 생성형 AI의 실제 고객·직원·제품·운영 배포와 성과는 확인 불가다.
