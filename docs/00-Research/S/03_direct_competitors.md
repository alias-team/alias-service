# MCM 직접 경쟁사 분석: Coach와 Tory Burch

> 조사 기준일: 2026-08-04. 이 문서는 공개 근거로 확인되는 직접 경쟁 맥락을 같은 차원으로 비교한다. 브랜드 자체 근거, 모기업·파트너 근거, 외부 추정을 분리하며 가격은 국가·통화·상품군이 다른 시점 스냅샷이다. 공개되지 않은 고객 구성·채널 비중·AI 성과는 추정하지 않는다. 점수·순위와 최종 문제·솔루션은 이 문서의 범위가 아니다.

## 1. 범위와 판정 원칙

- **필수 직접 경쟁사:** Coach와 Tory Burch를 포지셔닝, 가격, 제품, 고객, 글로벌 전략, 헤리티지, 아이콘, 유통, 매장, 전자상거래, CRM, 리포지셔닝, Gen Z, 콘텐츠, 앰배서더, 협업, 실적, AI의 동일한 18개 차원으로 검토했다.
- **법인·역량 귀속:** `Coach` 브랜드와 `Tapestry` 모기업을 분리한다. Tory Burch 브랜드와 Foundation·Shiseido·Maison Meta의 활동도 분리한다.
- **AI 상태:** 실제 운영, 단발성 캠페인, 전략·계획을 구분한다. 모기업이나 기술 파트너가 운영하는 기능은 해당 브랜드의 독자 시스템으로 쓰지 않는다.
- **증거 없음:** 공개 원문에서 확인되지 않은 항목은 `확인 불가`로 남긴다. 외부 매체가 인용한 비공개기업 실적은 회사 공시가 아니라 외부 추정으로 표시한다.
