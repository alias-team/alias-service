## Strategy A — S1-B 단독

| 항목 | 내용 |
| --- | --- |
| **범위** | 면세 매장 안. 한 번의 접점 |

## Strategy B — S1-B + 최소 Continuity

| 항목 | 내용 |
| --- | --- |
| **범위** | 면세 매장 + 다음 여정의 접점 |
| **Core AI** | **동일.** AI가 이 제품이 고객의 다음 여정 어느 장면에 놓이는지 판단한다 |
| **고객 흐름** | 매대 앞 → 목적지·기간 선택 → 장면 배치 → 결정 → **그 판단 하나가 Pass로 남는다** → 다음 여정에서 Pass를 제시하면 **같은 판단이 새 여정 기준으로 다시 돈다** |
| **Continuity** | **판단 결과 1건만 이어진다.** Customer Profile을 저장하지 않는다 |
| **LTV** | **직접 만들지 않는다.** Seed만 만든다 [`38` §3.6] |
| **저장** | `이 여정에서 이 제품이 어디 놓였는가` — **`누구인가`는 저장하지 않는다** |
| **트리거** | 🔒 **새 여정의 발생.** 시간 경과가 아니다 [`39` §4.1 판별선] |

| 항목 | 내용 |
| --- | --- |
| **범위** | 모든 여정. 무제한 축적 |
| **Core AI** | 동일 판단 + **축적된 여정 이력을 반영한 해석 조정** |

| **LTV** | 축적 자체가 LTV 장치 |
| **저장** | 여정 이력 전체 (익명 유지 시에만 채택) |

# Step 8. "한 문장 설명" 테스트

> 좋은 Solution은 **① 고객이 누구인지 ② 어떤 순간인지 ③ AI가 무엇을 판단하는지 ④ 경험이 어떻게 달라지는지**가 한 문장 안에 들어가야 한다.

## Strategy A

> **"공항 면세점에서 다음 목적지를 고르면, AI가 MCM 제품들이 그 여정의 어느 장면에 놓이는지 판단해, 가격이 아니라 여정으로 제품을 고르게 한다."**

| 요소 | 포함 |
| --- | --- |
| ① 고객 | 🟡 "공항 면세점에서"로 암시. 명시 없음 |
| ② 순간 | 🟢 목적지를 고르는 순간 |
| ③ AI 판단 | 🟢 어느 장면에 놓이는가 |
| ④ 경험 변화 | 🟢 가격 → 여정 |

**판정: 1문장. 🟢 통과.**

## Strategy B

> **"공항 면세점에서 다음 목적지를 고르면 AI가 MCM 제품이 그 여정의 어느 장면에 놓이는지 판단해 주고, 그 판단은 다음 공항에서 여정이 바뀌면 다시 달라진다."**

| 요소 | 포함 |
| --- | --- |
| ① 고객 | 🟡 암시 |
| ② 순간 | 🟢 목적지를 고르는 순간 + 다음 공항 |
| ③ AI 판단 | 🟢 동일 판단이 반복 |
| ④ 경험 변화 | 🟢 **여정이 바뀌면 답이 바뀐다** |

**판정: 1문장. 🟢 통과.** A보다 12자 길지만 **개념이 하나 더 들어가지 않았다** — `다시 달라진다`는 같은 판단의 반복이지 새 개념이 아니다.

## Strategy C

> **"공항 면세점에서 AI가 제품과 여정의 관계를 판단하고, 그 판단이 여정마다 쌓여서, 세 번째 여행에서는 첫 번째와 다른 경험이 된다."**
> ...그런데 **무엇이 쌓이는지**, **왜 달라지는지**, **개인정보는 어떻게 되는지**를 곧바로 설명해야 한다.

**판정: 🔴 1문장으로 끝나지 않는다.** `쌓인다`는 개념이 즉시 세 개의 후속 질문을 부른다.

> ## Complexity Risk: A 낮음 · B 낮음 · **C 높음**

# Step 9. 3분 Demo 테스트

## Strategy A

| 단계 | 내용 |
| --- | --- |
| **시작 장면** | 인천공항 면세 MCM 매대. 같은 백팩·토트·크로스백 세 개가 놓여 있다 |
| **AI 판단 순간** | 화면에서 `도쿄 · 2박 · 출장` 선택 |
| **Customer Before** | 세 제품이 가격표와 소재 태그로만 구분된다 |
| **Customer After** | 세 제품이 **이동일 아침 / 미팅 사이 / 돌아오는 날 저녁**이라는 세 장면에 각각 놓인다. **탈락한 제품은 없다** |
| **Clutch Moment** | 같은 화면에서 `발리 · 7일 · 휴가`로 바꾼다. **세 제품이 완전히 다른 세 장면으로 재배치된다** |
| **종료 장면** | "이 제품이 좋은가가 아니라, 당신의 다음 5일에 이 제품의 자리가 있는가" |

**3분 안에 이해 가능한가: 🟢 예.** 장면 전환 하나로 전달된다.

## Strategy B

| 단계 | 내용 |
| --- | --- |
| **시작 장면** | 인천공항 면세 MCM 매대. 세 제품 |
| **AI 판단 순간** | `도쿄 · 2박 · 출장` 선택 → 세 장면 배치 |
| **Customer Before** | 세 제품이 가격표와 소재 태그로만 구분된다 |
| **Customer After** | 세 장면 배치 + **"이 판단을 가져가시겠어요?"** → Pass 한 장이 저장된다 |
| **Clutch Moment** | 🔴 **화면이 넘어간다. `3개월 뒤 · 헬싱키 공항`.** 같은 고객이 Pass를 연다. **지난 도쿄 판단이 그대로 떠 있다.** 새 여정 `헬싱키 · 5일 · 겨울`을 입력한다. → **"도쿄에서는 미팅 사이의 가방이었습니다. 헬싱키 5일에는 그 자리가 없습니다."** 판단이 뒤집힌다 |
| **종료 장면** | "여정이 바뀌면 답이 바뀝니다. 브랜드가 그걸 기억하는 게 아니라, **판단이 다시 도는 겁니다**" |

**3분 안에 이해 가능한가: 🟢 예. 그리고 A보다 강하다.**

**이유(Inference·높음):** A의 Clutch는 `같은 화면에서 입력을 바꾸는 것`이라 **시뮬레이션처럼 보인다.** B의 Clutch는 `시간과 장소가 실제로 넘어가는 것`이라 **서비스처럼 보인다.** 그리고 마지막 대사가 **"기억하는 게 아니라 다시 도는 것"**으로 개인정보 질문을 선제 차단한다.

## Strategy C

| 단계 | 내용 |
| --- | --- |
| **시작 장면** | 동일 |
| **AI 판단 순간** | 동일 |
| **Customer Before/After** | 동일 |
| **Clutch Moment** | 🟡 **3회차·5회차의 판단이 1회차보다 나아진 것을 보여야 한다.** 그런데 **"나아졌다"를 화면으로 대비하기 어렵다** — 무엇이 얼마나 나아졌는지 설명이 필요하다 |
| **종료 장면** | 축적 그래프 또는 이력 화면 |

**3분 안에 이해 가능한가: 🔴 어렵다.** 축적의 가치는 **본질적으로 시간에 비례**하는데, Demo는 시간을 압축해야 한다. **압축하면 축적이 보이지 않고, 안 하면 3분을 넘긴다.**
