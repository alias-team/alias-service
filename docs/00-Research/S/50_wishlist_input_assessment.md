# 1. 🟢🟢 가장 중요한 발견 — MCM이 직접 지목한 신호다

> **"구매 intent 파악입니다. 방문 중 제품을 착장해보거나 혹은 이커머스에서 `장바구니에 담고 난 이후 구매가 이뤄지지 않을 때` 가장 아쉽습니다. 어떠한 형태로든 구매 전환 conversion을 방해하는 요소를 거둬 내고자 합니다."**
> — [QA-4-4, **A급 공식**]

**MCM이 유일하게 구체적으로 지목한 두 이탈 신호가 `착장`과 `장바구니`다.**

## 1.1 이것이 바꾸는 것

| 항목 | 이전 | 위시리스트 추가 후 |
| --- | --- | --- |
| **`21` E-04 Purchase Intent (9점)** | 🔴 **4/9 — 구매 이후만 다뤄 미충족** | 🟢 **7/9 — MCM이 지목한 신호를 직접 사용** |
| **`18` P-09 Read the Signal** | 🔴 해당 없음 | 🟢 **정면 정합** — "고객이 말이 아니라 행동으로 남긴 신호(착장·장바구니)를 읽는다" |
| **`20` F-05 필터** | 🔴 불통과 | 🟢 **통과** — "고객이 이미 구매 의향을 표출한 뒤 발생하는 문제인가" |

**이것이 이번 제안의 최대 가치다.** `45`부터 `49`까지 다섯 문서 내내 **E-04 미충족**이 반복 지적됐는데, 이 입력 하나가 그것을 푼다(Inference·높음).

## 1.2 ⚠️ 다만 완전 충족은 아니다

**MCM이 아쉬워한 것은 `담고 난 직후의 이탈`이다.** Personal Edit은 **시즌 후에** 다룬다.

```
[MCM이 지목한 순간]   장바구니에 담음 → ▶몇 분~며칠 안에 이탈◀
[Personal Edit]       장바구니에 담음 → ... 시즌이 바뀜 → ▶그때 개입◀
```

**신호는 같지만 개입 시점이 다르다.** 그래서 9/9가 아니라 7/9다.

**🔒 이 격차를 인정하고 프레이밍해야 한다:** *"장바구니 이탈을 그 자리에서 잡는 게 아니라, 그때 남긴 방향을 다음 시즌에 되살린다."*

# 2. 문제 1 해결도 — 🟡 부분

| 위시리스트 | Silver Charm | Travel Bag |

| **Edit** | 🟢 **다르다** | 🟢 **다르다** |

**같은 소유물을 가진 고객이 구분된다.** ✓

| --- | --- |
| Personalization 방향에 관심 | ? |
| **그냥 그 참이 예뻐서** | ? |
| 선물용 | ? |
| 가격이 저렴해서 담아 둠 | ? |

**위시리스트 아이템 1개에서 `방향`을 단정하는 것은 과잉 해석이다**(Hypothesis).

# 3. 문제 2 — 🔴 악화 위험

## 3.1 위시리스트 리타게팅은 가장 오래된 표준 기능이다

| 기존 기능 | 내용 |
| --- | --- |
| **Abandoned Cart Email** | 장바구니에 담고 안 산 제품을 다시 보여준다 |
| **Wishlist Alert** | 재입고·세일 알림 |
| **Browse Abandonment** | 본 제품 리타게팅 |

**심사 반박:** *"그거 장바구니 리마인더 아닌가요?"*

**위시리스트를 넣는 순간 이 반박이 강해진다**(Inference·높음).

## 3.2 🔒 구분선 — 제품인가 방향인가

| | Abandoned Cart | Personal Edit |
| --- | --- | --- |
| 쓰는 것 | 🔴 위시리스트의 **제품** | 🟢 위시리스트에서 추출한 **방향** |
| 말하는 것 | "그거 아직 안 사셨어요" | "당신이 관심 보인 **방향**이 이번 시즌 이렇게 나타났습니다" |
| Edit에 등장하는 제품 | 🔴 **위시리스트 그 제품** | 🟢 **그 제품이 아닌, 같은 방향의 이번 시즌 제품** |

**🔒 규칙: 위시리스트에 담긴 제품 자체를 Edit에 노출하지 않는다.** 노출하는 순간 리타게팅이다.

**사용자 예시는 이 규칙을 지키고 있다** — Silver Charm을 다시 보여주는 게 아니라 **Personalization 방향**을 읽었다. 다만 **설계 규칙으로 명문화되지 않으면 구현에서 무너진다.**

## 이 문서의 한계

1. **위시리스트 보유율·사용률에 대한 데이터가 0이다.** 이 문서의 §2.2가 전적으로 이 공백 위에 있다.
2. **§2.3의 "방향 추출이 과잉 해석"은 `Hypothesis`다.** 반대로 위시리스트가 방향을 잘 나타낼 수도 있으며 검증되지 않았다.
3. **점수는 `21` 프레임 기반의 `Inference`**이며 실제 심사 배점이 아니다.
4. **§4의 GATE 저촉 판정은 이 조사의 해석이다.** MCM이 위시리스트를 명시적으로 언급한 것은 아니다.
5. **`49`를 수정하지 않았다.**
