## Core Problem

**검증된 P2-05** [`31`, 81점, Kill Test PASS]:

> 면세 매장은 MCM 매출의 핵심 채널인데, 시간·공간·접객이 압축된 환경 때문에 브랜드 경험과 맞춤형 상호작용이 충분히 전달되지 않고, 특히 Global Gen Z 고객의 **구매 전환**과 **장기적인 브랜드 관계 형성**에 공백이 발생한다.

**핵심 근거 사슬** [`31` §2, Inference·높음]:

```
면세는 신규 브랜드 발견 채널이다            Gen Z 67%가 처음 사는 제품 구매
        ↓
MCM 주 타깃의 전환율이 거기서 가장 낮다      Gen Z 41% vs 평균 51%
        ↓
전환을 좌우하는 것은 사람의 상호작용이다      76%가 영향 인정
        ↓
그런데 절반 가까이가 상호작용 없이 나간다     상호작용률 54~56%
        ↓
MCM 매출의 90%+가 이 구조에서 나온다         [A급 공식]
```

**🔴 이 Solution이 다루지 않는 부분을 명시한다.** 위 사슬의 마지막 두 줄(비접촉 고객 44~46%)은 **`34` C2(Silent Signal)의 영역**이며 이 Solution은 거기에 도달하지 않는다.

## Core AI Decision

> **AI가 고객과 제품의 관계를 `지금의 여정` 기준으로 다시 해석한다.**

| 항목 | 내용 |
| --- | --- |
| **입력** | 다음 목적지 · 기간 · 여정의 성격 / 후보 제품의 소재·용량·형태 |
| **판단** | 이 제품이 그 여정의 **어느 장면에 놓이고 어느 장면에는 놓이지 않는가** |
| **출력** | 🔒 **장면.** 제품 집합도, 순위도, 적합도 점수도 아니다 |
| **반복** | 여정이 바뀌면 **같은 판단이 다시 돌아** 다른 답을 낸다 |
| **🔒 AI 개수** | **하나.** 구매 후 AI도, CRM AI도 없다 [`39` §4.2] |

### 🔒 설계 규칙 — 위반 시 즉시 Generic Recommendation으로 회귀 [`38` §2.3]

| # | 규칙 |
| --- | --- |
| **R-1** | **어떤 제품도 탈락하지 않는다.** 모든 후보에 자리가 주어진다 |
| **R-2** | **출력의 주어는 제품이 아니라 장면이다** |
| **R-3** | **비교급·최상급 금지** — `더 적합`·`가장 잘 맞는`·`Best` |
| **R-4** | **점수·퍼센트·별점 금지** |
| **R-5** | **`추천`이라는 단어를 UI·피칭·문서 어디에도 쓰지 않는다** |

## Conversion Logic

```
[문제]  매장 내 구매 포기의 약 3/4이 가격 관련                      [B급]
        Gen Z·밀레니얼 59%가 여정 중 온라인 가격 확인                [A/B급]
              ↓
[진단]  가격 축에서 정면 승부하면 진다                              (Inference)
              ↓
[개입]  비교의 축 자체를 `가격·스펙` → `내 다음 여정`으로 옮긴다
              ↓
[근거]  고객이 이미 축을 옮기고 있다
        가격 동기 26% → 17% 하락 / 경험 동기 45%, Gen Z 49%        [A/B급]
              ↓
[기대]  Gen Z 면세 전환율 41% → 전 연령 평균 51%에 근접             (Hypothesis)
```

**⚠️ 마지막 줄은 `Hypothesis`다.** 축을 옮기면 전환이 오른다는 **직접 인과 데이터를 확보하지 못했다** [`28` P2-05 Evidence Gap 1].

**⚠️ `21` E-04와의 부분 충돌을 기록한다.** E-04는 **"착장·장바구니 이후"**의 이탈을 요구하는데 [QA-4-4, Fact], 이 Solution이 개입하는 `비교` 구간은 **의향 표출 직후이긴 하나 MCM이 지목한 두 신호와 정확히 같지는 않다** [`38` §1.6].

## LTV Logic

> ## 🔒 **LTV를 직접 만들지 않는다. Seed만 만든다.**

**근거 세 가지** [`38` §3.5]:

| # | 근거 |
| --- | --- |
| **1** | MCM 자신의 인과 구조에서 **"Engagement는 수단이고 LTV는 결과"**다 [`15` §8]. LTV를 직접 만들려는 시도는 결과를 원인 자리에 놓는 것이다 |
| **2** | **실측.** LTV를 직접 만들려 한 S3-B가 `36`에서 9개 중 최하위 46점이었다 — 사유는 개인 이력 요구(GATE-1 위험) + **CRM 자동화와 구분 불가** |
| **3** | **판단의 보존은 새 기능이 아니다.** 같은 Core AI의 출력을 저장할 뿐이므로 `21` E-10(Single Core Capability)을 해치지 않는다 |

**Seed의 정확한 정체:**

```
S1-B의 LTV 결핍 원인 = 판단이 매장을 나가는 순간 휘발된다        [`38` §1.7]
                        ↓
필요한 것 = 새 기능이 아니라  ▶ 그 판단의 보존 ◀
                        ↓
보존된 판단 = 다음 여정에서 다시 쓰일 수 있는 것 = LTV Seed
```

**🔒 판별선:** 다음 접점의 트리거는 **`시간 경과`가 아니라 `새 여정의 발생`**이어야 한다. 시간 트리거 = CRM = 탈락 [`39` §4.1].
