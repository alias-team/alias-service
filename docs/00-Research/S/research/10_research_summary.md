# MCM 해커톤 리서치 종합 보고서

> 조사 기준일: 2026-08-04. 이 문서는 `research/00`~`09`와 세 출처 장부를 의사결정용으로 압축한다. `사실`은 출처가 직접 확인하는 내용, `추론`은 복수 사실의 제한적 해석, `가설`은 직접 검증이 필요한 가능성, `비공식 참고`는 대표성을 주장할 수 없는 고객 게시물이다. 공개되지 않은 내부 상태는 `확인 불가`이며 부재나 열위로 바꾸지 않는다. 이 보고서는 최종 문제 우선순위와 구체 솔루션을 정하지 않는다.

## 1. 규정

- **행사·일정 — 확인됨:** 공식 주제는 “AI는 럭셔리 경험을 어떻게 혁신할 수 있을까?”이고, SJF 트랙은 `AI 기반 프로덕트`, `인터랙티브 리테일`, `360° 고객 경험`으로 구성된다. 개발 기간은 2026-07-23~08-20, 공식 제출 마감은 2026-08-21 09:59:59, 행사일은 2026-08-25다. [OFF-001·OFF-009·OFF-019]
- **100점 심사 — 확인됨:** 문제 정의 25, 실현 가능성 20, 시장성 15, UI/UX 10, 전달력 10, 트랙 적합성 20이다. 트랙 적합성은 파트너 실제 보유 자산을 핵심 근거로 쓰는 영역 정합성 10과 브랜드 가치를 해치지 않고 강화하는 브랜드 톤 정합성 10으로 나뉜다. [OFF-003·OFF-020·OFF-022]
- **구현 경계 — 확인됨:** 웹은 실제 배포·작동이 기본이고 임의 데이터나 미연결 기능은 감점될 수 있다. AI는 실제 사용자 흐름과 연결돼야 하며 자체 모델은 필수가 아니다. 앱은 실제 흐름에 가까운 영상 중심 평가가 허용될 수 있다. [OFF-004·OFF-012·OFF-013·OFF-014]
- **필수 제출 — 확인됨:** 프로젝트 정보·이미지·영역별 기술 스택·각 1,500자 이내 기획안·100초 이내 MP4·16:9 PDF Deck·배포 URL·Public GitHub가 필요하다. 저장소는 최대 3개, 평가 브랜치는 `main` 또는 `master`이고 배포물과 대응해야 한다. [OFF-005·OFF-010·OFF-016·OFF-021]
- **현장 — 확인됨:** 트랙당 2팀, 총 8팀이 본선에 진출한다. 트랙 피칭 5분, 라운드 1 발표 5분·Q&A 8분, 라운드 2 라이브 시연 3분·기술 Q&A 5분, 결선 100초+100초다. [OFF-011·OFF-023]
- **확인 필요:** 참가 자격·팀 구성, 사전 개발, GitHub 동결의 정확한 시점, API·크레딧 조건, 데이터·IP·개인정보, 복수 챌린지, 라운드별 가중치와 제출 세부는 공식 자료에 없다. 상세 질문은 [09_questions_to_verify.md](09_questions_to_verify.md)에 있다.

## 2. 리스크

- **실격·감점:** 제출 이후 또는 마감 후 GitHub 변경, 비공개 저장소·평가 브랜치 오류, 배포와 레포 불일치, 작동하지 않는 웹·AI, 행사 종료 전 URL 장애가 직접 위험이다. 최초 제출 시점의 동결 규칙은 확인이 필요하다. [OFF-004·OFF-005·OFF-013·OFF-015·OFF-017]
- **권리·신뢰:** 공개 영상과 Public GitHub 때문에 로고·제품 이미지·음원·폰트·오픈소스·개인정보·비밀키의 권리와 보안 위험이 커진다. MCM 공개 콘텐츠 열람은 재사용 허가가 아니고, 고객·CRM·DPP 백엔드 접근권도 확인되지 않았다. [OFF-005·OFF-021·OFF-304·OFF-312·OFF-313]
- **브랜드·심사:** 파트너 자산을 실제 사용할 권한 없이 전제하거나, 브랜드 근거 없이 자동화·과장 표현을 붙이면 트랙 적합성과 신뢰가 약해질 수 있다. 이는 규정과 공개 권리 상태를 결합한 **추론·중간**이다. [OFF-020·OFF-312]
- **운영:** 외부 API 한도·네트워크·인증·크레딧 만료, 라이브 시연 실패, 지각, 잘못된 PDF·파일명이 발표와 실현 가능성에 영향을 줄 수 있다. 구체 조건은 Q-03·Q-09~Q-13에서 확인한다.

## 3. 법인·조직·자산 관계

- 성주재단은 별도 고유번호와 대표자를 표시하는 여성복지재단이다. 성주그룹·MCM과 동일 조직으로 쓰지 않는다. [OFF-301]
- 성주그룹은 2005년 MCM 본사 인수와 글로벌 사업 전개를 공식 서술하지만, 그 역사만으로 현재 개별 법인의 주주·지분·자산 권리자를 확정할 수 없다. [OFF-302]
- `MCM`은 브랜드명이고 단일 법인명이 아니다. `MCM Products AG`는 UID `CHE-228.162.099`를 유지한 채 2023-02-16 `MCM Global AG`로 상호가 바뀌었다. MCM Global AG는 그룹 고객 DB 운영 주체이자 공식 사이트 제공·스위스 온라인 판매 주체로 확인된다. [OFF-303·OFF-304·OFF-305·OFF-318]
- `MCM Holding AG`는 별도 UID의 스위스 법인이며, 등기 목적만으로 모회사·실제 IP 보유자를 확정하지 않는다. 캐나다의 `VISETOS`와 `Laurel Wreath Device` 두 등록은 Trias Holding AG를 현재 권리자로 표시하지만 이를 전 세계 상표 소유관계로 확대하지 않는다. [OFF-306·OFF-316·OFF-317]
- 주식회사 엠씨엠코리아는 한국 공식몰 사업자이자 MCM 그룹 소속 개인정보 처리 법인으로 확인된다. 해커톤의 데이터·IP·브랜드 승인 주체는 여전히 확인 불가다. [OFF-304·OFF-308]

## 4. MCM 컨텍스트와 포지셔닝

- **기원·코드 — 사실·높음:** MCM은 1976년 뮌헨 여행·제트세트 문화에서 시작했고 Visetos, 월계수, 바이에른 다이아몬드, 코냑 색상, 이동성을 반복한다. 성주그룹은 2005년 독일 MCM 본사를 인수하고 MCM 글로벌 사업을 전개한다고 공식 서술한다. [OFF-302·OFF-401]
- **장기 언어와 최근 실행 — 사실·중간~높음:** `Global Nomad`·`New School of Luxury`는 장기 정체성이고, 2023년 이후 `Made for Movement`·`Mavericks`·`Digital Nomads`·`Smart Luxury`는 이동하는 생활자와 합리적 가격·기능·책임을 더 구체화한다. 서로 같은 용어로 취급하지 않는다. [OFF-307·OFF-403·OFF-404·IND-002·IND-003]
- **2023–2026 변화 — 사실 + 추론:** 백팩·스트리트 단일 연상에서 헤리티지 회복과 풀 라이프스타일로 재정렬하며 RTW·아이웨어·향수·홈·여행·지속가능 소재·DPP까지 확장했다. 2026년 50주년은 미래주의를 유지하면서 원형 아이콘·뮌헨 문화·장기 사용을 더 전면화한다. 후자가 2023 전략의 폐기보다 정당성 보강이라는 해석은 **추론·중간**이다. [OFF-402~OFF-409·OFF-415·OFF-416·OFF-423·OFF-424]
- **현재 디지털 상태 — 사실·높음:** 국가별 e-commerce, 계정·위시리스트·추천 표시, 주문·반품, 매장 찾기, CRM·프로파일링 처리 목적, 일부 스타일의 NFC/Aura DPP가 확인된다. DPP는 AI가 아니며 국가·채널 통합도와 성과는 확인 불가다. [OFF-308·OFF-311·OFF-313·OFF-411·OFF-412·OFF-421]
- **성과 경계:** 최신 그룹 연결 매출·이익·시장점유율·지역/채널/상품 실적, 고객 구성·재구매·NPS·CLV, 최신 총매장 수, CRM·재고·AI 성과는 공개 근거에서 확인되지 않았다. 소수 고객 게시물의 내구·가치 호평, 로고 호불호, 서비스 호평·불만은 모두 **비공식 참고·낮음**이다. [CUS-001~CUS-007]

## 5. 하이엔드 목표

- 공개 근거는 MCM이 `Smart Luxury`, 완전한 라이프스타일 하우스, 기존 고객 유지와 신규·젊은 고객 확대를 지향하고 50주년에 헤리티지·정교함·장기 사용을 강조한다는 사실까지 지지한다. [OFF-307·OFF-408·OFF-409·IND-002·IND-003]
- `하이엔드 전환`이라는 공식 프로그램의 기준연도·목표시장·가격 단계·인지·정가 판매·재구매·서비스 지표와 완료 조건은 확인 불가다. 따라서 “전환 완료”나 특정 상위 브랜드와의 동급 목표를 주장하지 않는다. Q-17의 공식 답변이 필요하다.
- 비교를 위한 임시 기준은 핵심 역사·아이콘이 상품, 가격·접근, 매장·디지털, 사람 서비스, 수선·제품 생애에서 일관되게 증명되는 상태다. 이는 네 벤치마크의 공통 관찰에서 얻은 **연구자 추론·중간**이며 MCM의 공식 목표가 아니다. [04_high_end_benchmarks.md §5](04_high_end_benchmarks.md)

## 9. 미래 방향

- **공식 계획:** MCM 수요예측 탐색, Ask Ralph의 브랜드·플랫폼·시장 확장, Dior GEO 개발이다. 의도는 사실이지만 출시·완료·성과는 보장되지 않는다. [FS-01~FS-03]
- **강한 신호:** 직원용 Advisor 보조, 구색·수요·재고 운영 AI, 반복되는 AI 위조 탐지, 브랜드가 통제하는 스타일·제품·헤리티지 해석층이 복수 사례에서 겹친다. 보편 표준이라는 뜻은 아니다. [FS-04~FS-07]
- **산업 전망:** 발견 접점이 범용 AI로 분산되고 개인화 기대와 인간 접촉 요구가 함께 높아질 가능성이 설문에 나타난다. McKinsey 럭셔리 하위표본은 31명, EY는 열망형 고객 1,631명이므로 MCM 수요·ROI로 전환하지 않는다. [FS-08·FS-09]
- **연구자 추론:** 창의·공예 AI의 승인 경계, 데이터·권리·평가의 선행성, 단발 캠페인의 반복·측정 필요성이 중요해질 수 있다. 반증 가능한 방향이지 공식 투자 계획이 아니다. [FS-10~FS-12]

## 11. 격차

- **관찰 격차:** 공개 실행 차이만 말할 수 있는 영역은 핵심 코드의 접점 연속성, 희소성·유통 장치, 사람과 디지털의 연결, 구매 후 관계, 공예·제품 근거, AI 배포 단계다. 실제 고객·사업 영향과 원인은 대체로 확인 불가다. [07_mcm_gap_analysis.md](07_mcm_gap_analysis.md)
- **증거 공백:** 글로벌 인지도, Gen Z 고객 구성, 가격 정당성, VIP 경제성, 최신 매장·채널 성과, 고객 데이터 통합도, DPP 범위·성과, AI ROI는 비교 가능한 공개 근거가 부족하다. 비공개는 부재나 열위가 아니다.
- **현재 확인된 프로젝트 제약:** 2026-08-04 현재 팀에 제공된 기업 내부 데이터와 MCM·성주 임직원 접근이 없다는 사용자 제공 조건은 사실·높음이다. 향후 데이터·API·샌드박스·담당자 제공 여부와 MCM 내부 준비도는 확인 불가다.
- **점수화 불가:** 국가·통화·상품군이 다른 가격, 정의가 다른 매장 수, 불완전한 고객·VIP·AI 성과를 합쳐 브랜드나 격차 순위를 만들 수 없다.

## 12. 고유 자산

- **브랜드·상품:** 1976 뮌헨 여행·제트세트·음악, Visetos 월계수·다이아몬드·코냑, `Global Nomad`, 독일×한국, Stark·Ottomar·Liz·Dia, 이동·내구·반항의 코드가 있다. [OFF-307·OFF-401·OFF-408·OFF-409·IND-003]
- **접점:** 국가별 자사몰, 부티크·백화점·여행 리테일, 계정·상품 카탈로그·매장 찾기·반품·수선 공개 기능과 현지 한정 협업이 확인된다. [OFF-308·OFF-311·OFF-417·OFF-419·OFF-421·IND-007·IND-008]
- **제품 생애·책임:** 일부 스타일의 NFC/Aura DPP, 소재·제조·환경·인증 정보, MIRUM·ECONYL·GOTS 대상 소재와 공급망 가시성 방향이 확인된다. [OFF-313·OFF-314·OFF-418]
- **접근 경계:** 공개 상품·매장·헤리티지·보고서는 열람 가능하지만 대량 수집·재사용 권리, 내부 카탈로그·재고·고객·수선·DPP 백엔드/API, 브랜드 원본 에셋은 참가자 접근이 확인되지 않았다. 보유 사실과 해커톤 접근 가능성을 분리한다.

## 14. 확인 불가 정보

메인 격차 분석을 바꿀 수 있는 고영향 공백은 다음과 같다.

1. 공식 하이엔드 전환 목표·기준선·시장·성과지표와 2026년 현재 진척.
2. 제품·채널별 full-price 판매, 할인·재고·sell-through, 한정 수량·배정, 대표 제품과 가격 정당성.

4. VIP·로열티·Client Advisor의 실제 운영, 계정·매장·e-commerce·수선 데이터 연결과 성과.

6. 아카이브·공예·품질·콘텐츠 근거, 권리 상태, 브랜드 어조·승인 책임과 측정.
7. MCM 실제 AI 목록, 사용자·업무·단계, 데이터·모델·평가·보안·사람 승인·ROI·중단 기준.
8. 해커톤에 향후 제공될 데이터·API·샌드박스·실물·담당자·고객 리서치 경로와 사용권·동의.
