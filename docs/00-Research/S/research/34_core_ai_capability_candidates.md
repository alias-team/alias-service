### DEC-01. AI가 **이 제품이 고객의 다음 여정에서 어떻게 쓰일지**를 판단한다

| 항목 | 내용 |
| --- | --- |
| **Core Decision** | 고객의 다음 목적지·기간·여정 성격에서 이 제품이 실제로 어느 장면에 놓이는지를 판단한다 |
| **Input Signal** | 게이트·목적지(고객 자발 제공), 여정 기간, 현재 들고 있는 짐 구성, 대상 제품의 소재·용량·형태 |
| **Why AI** | 취항지 수백 × 기간 × 목적 × 제품 = 수만~수십만 조합 [`33` Q6]. **사전 제작 불가**이고 **직원이 전 세계 목적지를 알 수 없다** |
| **Customer Value** | "여행에 좋아요"가 아니라 **"당신의 방콕 5일에서 이 가방이 놓이는 자리"**를 받는다 |
| **Business Value** | Conversion (구매 확신) + LTV (제품이 여정의 일부가 됨) |
| **Proactivity** | 🟢 가능. 게이트 정보만으로 고객이 묻기 전에 작동 |
| **MCM Specificity** | 🟢 **최고.** 1976년 뮌헨 여행 헤리티지 · Made for Movement · Global Nomad [A급 공식]. **면세 매장은 고객의 다음 목적지를 알 수 있는 유일한 리테일 접점** |
| **Luxury Fit** | 🟢 강화. 제품을 스펙이 아니라 **삶의 장면**으로 제시 |
| **Privacy** | 🟢 가능. **목적지는 개인 식별자가 아니다.** 게이트 번호는 공개 정보 |

## Step 5. AI Necessity Kill Test

> **"AI를 제거하고 직원 + 콘텐츠 + Rule-based 시스템으로 바꿔도 핵심 Customer Value의 80% 이상이 남는가?"**
> **YES면 탈락.** AI를 제거했을 때 핵심 가치 자체가 무너지는 후보만 유지한다.

| # | Decision | AI 제거 시 Non-AI 대체안 | 남는 가치 | 판정 |
| --- | --- | --- | --- | --- |
| **DEC-01** | 다음 여정 적합성 | 직원이 "어디 가세요?" 묻고 **"여행에 좋아요"** 수준의 일반 답변. 목적지별 포스터 몇 종 | **약 20~30%.** 구체성이 가치의 전부인데 그것이 사라진다. 직원이 방콕·리야드·헬싱키의 다음 3일을 알 수 없다 | 🟢 **생존** |
| **DEC-02** | 진입점 판단 | 직원 증원(도달 못 한 고객이 정의), 사이니지·연출(모두에게 동일) | **약 10~20%.** 개별 개입이라는 가치의 핵심이 사라진다. 개입의 76% 영향력은 개별성에서 나온다 | 🟢 **생존** |
| **DEC-03** | 주의 예산 판단 | "5분 코스 / 15분 코스" 동선 안내, 숙련 직원의 눈치 | **약 60~70%.** 시간 구간을 3~4개로 나누면 근사된다 | 🟡 **경계 → DEC-02에 통합** |
| **DEC-04** | 개입 대상 판단 | 직원의 직관과 경험 | **약 50~60%.** 2~3명까지는 사람이 더 낫다. **5명 이상 동시에서만 무너진다** | 🟡 **경계 → DEC-02에 통합** |
| **DEC-05** | 다음 접점 판단 | QR → 이메일 수집 → 뉴스레터, "구매 30일 후" 룰 | **약 40~50%.** 연결은 되지만 **여정 일정 기반 타이밍**은 룰로 불가. 다만 럭셔리 반복구매율 9.9%가 Non-AI 방식의 한계를 보여준다 | 🟡 **조건부 생존** |
| **DEC-06** | 사전 지식 판단 | 두 층위 콘텐츠 병렬 배치, 직원 대화 | **약 80~85%.** 콘텐츠 설계로 커버된다 | 🔴 **탈락** |
| **DEC-07** | 짐 조합 판단 | 직원이 눈으로 보고 조언, 표준 더미 비치 | **약 70~80%.** 그리고 **오프라인 실측은 MCM이 덜 효과적이라 답한 방향** [QA-3-2, A급 공식] | 🔴 **탈락** |
| **DEC-08** | 헤리티지 순간 선택 | 잘 만든 콘텐츠 라이브러리 + 큐레이션 + 헤리티지 벽면. **산업 표준 대응** [B급] | **약 80~85%.** `32` D-11 탈락 판정과 일치. **AI 도슨트로 회귀** | 🔴 **탈락** |
| **DEC-09** | 망설임 종류 판단 | 직원이 "무엇이 고민되세요?"라고 묻는다 | **약 85%.** 한마디로 해결된다 | 🔴 **탈락** |
| **DEC-10** | 개입/물러남 판단 | 숙련 직원의 판단. "말 걸지 않는 존" 설계 | **약 70%.** 다만 DEC-02가 성립하려면 필수 조건 | 🟡 **경계 → DEC-02에 통합** |

### 🔴 가장 중요한 탈락 — DEC-08

**"MCM 50년 자산 중 지금 이 순간에 닿는 하나를 판단한다"는 매력적이지만 Kill Test를 통과하지 못한다.**

잘 만든 콘텐츠 라이브러리와 큐레이션으로 80~85%가 남는다. 이것은 `32` Step 2에서 **D-11(브랜드 가치 전달)이 탈락한 것과 같은 결론**이며, 산업이 실제로 그렇게 대응하고 있다 [B급]. **P2-05를 "브랜드 이야기를 잘 들려주는 문제"로 다루면 AI 필연성이 없다**(Inference·높음).

### 🟡 통합의 근거 — DEC-03·04·10이 DEC-02의 구성 요소인 이유

세 판단은 단독으로는 Non-AI 대체가 60~70% 가능하지만, **DEC-02(진입점 판단)를 실행하려면 셋 다 필요하다.**

```
DEC-10 지금 개입해도 되는가?   → 아니면 아무것도 하지 않는다
DEC-04 여러 명 중 누구인가?     → 동시성
DEC-03 얼마나 깊게 할 것인가?   → 남은 주의의 크기
        ↓ 셋이 함께 있어야
DEC-02 이 사람에게 무엇을 보일 것인가
```

**즉 DEC-02는 단일 판단이 아니라 네 겹의 판단이며, 그 결합이 Non-AI 대체를 불가능하게 만든다**(Inference·높음).

## C1. Journey-Fit Judgment — 다음 여정 적합성 판단

| 항목 | 내용 |
| --- | --- |
| **Core AI Capability** | 고객의 다음 여정과 제품 사이의 적합성 판단 |
| **One-line Definition** | **AI가 "이 제품이 당신의 다음 여정 어디에 놓이는가"를 판단한다.** |
| **AI가 판단하는 것** | 목적지·기간·여정 성격 × 제품의 소재·용량·형태 → **이 제품이 실제로 쓰이는 장면과 쓰이지 않을 장면** |
| **AI가 없다면 불가능한 이유** | 취항지 수백 × 기간 × 목적 × 제품 = 수만 조합. **사전 제작 불가**, **직원이 전 세계 목적지를 알 수 없다.** Non-AI 대체 시 "여행에 좋아요" 수준으로 붕괴 (가치 20~30% 잔존) |
| **Customer Signal** | 게이트·목적지(자발 제공), 여정 기간, 관심 제품 |
| **AI Output** | 그 여정의 구체적 장면에 놓인 제품의 역할 판정 |
| **Customer Action** | 제품을 자기 여정의 일부로 인식 → 구매 결정 |
| **Business Outcome** | Conversion ↑ (확신) · LTV ↑ (제품이 여정의 일부가 됨) |
| **반복 사용 이유** | 🟢 **여정이 바뀔 때마다 답이 바뀐다.** 다음 출장, 다음 여행마다 다시 유효 |
| **MCM 세계관 연결** | 🟢 **최고.** 1976년 뮌헨 여행 제품 · `Made for Movement` · `Global Nomad` [A급 공식]. 브랜드 원점과 판단 대상이 일치 |
| **Global Gen MZ 연결** | 🟢 디지털 노마드의 정의가 이동이다 [A급 공식] |
| **Luxury Guardrail** | 🟢 제품을 스펙이 아니라 **삶의 장면**으로 제시 → Craftsmanship·UVP 강화. 실측 판정이 아니므로 [QA-3-2] 정합 |
| **MVP 구현 난이도** | 🟢 **낮음.** 목적지·제품 더미 데이터 + 공개 제품 정보. 개인 식별 불필요 |

## C2. Silent Signal Judgment — 말하지 않는 고객의 개입 판단

| 항목 | 내용 |
| --- | --- |
| **Core AI Capability** | 접촉하지 않은 고객의 행동 신호에서 개입 여부·대상·깊이·내용을 동시에 판단 |
| **One-line Definition** | **AI가 "지금 말을 걸지 않은 이 사람에게, 개입할지·무엇을 보일지"를 판단한다.** |
| **AI가 판단하는 것** | ① 지금 개입해도 되는가(DEC-10) ② 여럿 중 누구인가(DEC-04) ③ 얼마나 깊게(DEC-03) ④ 무엇을 보일 것인가(DEC-02) — **네 겹의 결합 판단** |
| **AI가 없다면 불가능한 이유** | **44~46%가 직원 접촉 없이 나간다** [E5, Fact]. 직원은 정의상 도달하지 못했고 콘텐츠·사이니지는 모두에게 같아 개별 개입이 아니다. 신호 6개 이상을 몇 초 안에 통합해야 하며 5명 이상 동시에서는 사람이 불가. Non-AI 대체 시 가치 10~20% 잔존 |
| **Customer Signal** | 익명 세션의 체류·집어듦·되돌아옴·이동 방향·속도·남은 시간 |
| **AI Output** | 개입/비개입 판정 + 개입 시 단 하나의 진입점 |
| **Customer Action** | 지나칠 자리에서 멈춘다 |
| **Business Outcome** | Conversion 직결. 개입받은 사람의 **76%가 결정에 영향** 인정 [E4, Fact] |
| **반복 사용 이유** | 🟡 **중간.** 방문할 때마다 작동하나 고객이 "쓴다"고 인지하지 않을 수 있다 |
| **MCM 세계관 연결** | 🟡 **중간.** 면세라는 무대는 특수하나 판단 구조는 브랜드 무관. **MCM 자산을 진입점 내용에 넣어야 특수성이 생긴다** |
| **Global Gen MZ 연결** | 🟢 Gen Z 전환율 41% vs 51% [E1, Fact]가 이 지점의 갭 |
| **Luxury Guardrail** | 🔴 **가장 위험.** 관측 수단이 감시로 인식되면 위반. **개입이 아니라 "준비된 상태"로 표현돼야 한다.** DEC-10(물러남 판단)이 필수 구성 요소인 이유 |
| **MVP 구현 난이도** | 🟡 **중간.** 판정 로직은 합성 신호로 시연 가능하나 **실제 신호 수집 방식이 미해결** |

## C3. Continuation Timing Judgment — 다음 접점 시점 판단 ⚠️ 조건부

| 항목 | 내용 |
| --- | --- |
| **Core AI Capability** | 고객의 여정 일정 안에서 브랜드가 다시 나타나야 할 시점과 이유를 판단 |
| **One-line Definition** | **AI가 "이 고객의 여정 어느 지점에서 다시 나타나야 하는가"를 판단한다.** |
| **AI가 판단하는 것** | 목적지·체류 기간·구매 제품 → **제품이 실제로 쓰일 시점**과 그때 유효한 이유 |
| **AI가 없다면 불가능한 이유** | ⚠️ **약하다.** 룰로 "구매 30일 후"는 가능하다. 다만 **고객이 이동 중이면 30일 후는 다른 나라**이고, 여정 일정 × 제품 사용 시점 조합은 룰로 표현되지 않는다. **Non-AI 대체 시 40~50% 잔존 — 세 후보 중 가장 높다** |
| **Customer Signal** | 목적지·체류 기간·구매 제품·구매 목적(자발 제공 범위) |
| **AI Output** | 다음 접점의 시점 + 그때의 이유 |
| **Customer Action** | 여행 중 또는 귀국 후 브랜드를 다시 만난다 |
| **Business Outcome** | **LTV 직결.** MCM 지정 방향(오프라인 → 온라인) [QA-3-1, A급 공식] |
| **반복 사용 이유** | 🟢 **높음.** 여정마다 반복 |
| **MCM 세계관 연결** | 🟡 중간~높음. 이동 고객 구조 [A급 공식] |
| **Global Gen MZ 연결** | 🟢 이동이 전제 |
| **Luxury Guardrail** | 🔴 **위험.** 과하면 마케팅 알림이 되고 **단순 CRM 자동화로 회귀**한다 |
| **MVP 구현 난이도** | 🟢 낮음. 다만 **시간 경과를 3주 안에 시연하기 어렵다** |

**⚠️ C3는 조건부 채택이다.** Kill Test에서 40~50%가 잔존해 C1(20~30%)·C2(10~20%)보다 AI 필연성이 약하다. **그럼에도 남긴 이유는 MCM이 지정한 방향(오프라인 → 온라인)과 Business Goal(LTV)이 C1·C2만으로는 닿지 않기 때문**이다(Inference). **C3 단독으로는 AI 문제로 성립하기 어렵다.**

| | 근거 |

| **가장 위험한 자리** | **C2(Silent Signal).** AI 필연성은 최고이나 **관측 수단이 감시로 인식되면 Luxury Guardrail을 위반**한다 |

## 이 문서의 한계

1. **Kill Test의 "남는 가치 %"는 이 조사의 판단(`Inference`)**이며 실측이 아니다.
2. **조합 규모 추정은 산정치**다.
3. **C2의 신호 수집 방식이 미해결이다.** 카메라·센서·자발 입력 중 무엇이 가능한지 검토하지 않았다.
4. **C3의 AI 필연성이 약하다는 것을 명시했다.** 다음 단계에서 강화되지 않으면 탈락 대상이다.
5. **MCM 자체 면세 데이터가 전무하다.**
6. **아직 Solution을 만들지 않았다.** `35`에서 시작한다.
