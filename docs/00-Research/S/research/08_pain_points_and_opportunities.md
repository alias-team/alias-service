# MCM 페인 포인트와 기회 영역 등록부

> 조사 기준일: 2026-08-04. 아래 항목은 순서를 우선도·가치·난이도 점수로 사용하지 않는 미정 목록이다. `확인된 문제`는 공개 근거 또는 프로젝트 조건이 명시된 범위의 문제 존재를 직접 확인하는 경우, `강한 추론`은 복수 사실이 같은 방향을 지지하지만 MCM 고객·내부 성과 검증이 남은 경우, `초기 가설`은 직접 고객·운영 근거가 부족한 경우다. 기회 영역은 이후 검증할 질문의 범위이며 구체 설계나 채택 결정을 포함하지 않는다.

## 1. 판정과 AI 도전 규칙

- 공개되지 않은 내부 역량은 `없음`으로 쓰지 않는다. 외부 조사자에게 근거가 없다는 문제와 MCM 내부에 역량이 없다는 주장을 분리한다.
- **현재 프로젝트 조건:** 2026-08-04 현재 팀이 제공받은 기업 내부 데이터는 없고 MCM·성주 임직원 접근도 없다. `docs/superpowers/specs/2026-08-04-mcm-hackathon-research-design.md` §2에 기록된 사용자 제공 사실이며 신뢰도는 높음이다.
- **미래 제공 가능성:** 주최·파트너가 이후 데이터·API·샌드박스·담당자 또는 고객 리서치 경로를 제공할지는 Q-04·Q-16·Q-19·Q-23에서 확인할 미확정 사항이다. 현재 미제공 사실을 앞으로도 계속 제공되지 않을 것이라는 주장이나 MCM 내부 자산 부재로 확대하지 않는다.
- **안전 기본값:** 공식 제공 범위·사용권·동의가 확인되기 전에는 내부 데이터·시스템·임직원 접근을 사용하지 않는다는 운영 원칙을 적용한다. 이는 미래 상태에 대한 사실 주장이 아니다.
- 고객 게시물은 반복 주제를 찾는 낮은 신뢰도의 신호일 뿐 빈도·시장 규모·원인을 증명하지 않는다.
- `왜 AI가 필요한가`는 언제나 조건부 질문이다. 대량·다국어·비정형·실시간 판단이 확인되지 않으면 AI 필요성을 인정하지 않는다.
- 각 항목은 `AI 없이 가능한가`를 별도로 기록한다. 정책·상품·유통·공예·서비스 기준과 사람 관계가 핵심이면 비AI 대응이 선행될 수 있다.
- 경쟁사·벤치마크의 기술은 성과 보장이 아니다. 모기업·파트너 데이터와 MCM의 접근 가능한 자산을 동일시하지 않는다.

## 2. 미정 페인 포인트·기회 영역

| 고유 MCM 자산 | 현재 확인 가능한 공개 상품·매장·헤리티지·DPP 소개와 지속가능성 보고서. 고객 DB·재고·수선·DPP 백엔드는 현재 팀에 제공되지 않았고 향후 제공 가능성은 확인 불가다. 공식 승인 전에는 사용하지 않는 것을 안전 기본값으로 둔다. |
| AI가 필요할 수 있는 이유 | 현재 문제는 데이터 접근과 검증 권한이므로 AI 필요성이 없다. 권한 없는 데이터를 AI가 복원할 수 있다는 주장은 기각한다. |
| AI 없이 가능한가 | **AI 없이 가능.** 공개 근거 추적과 외부 고객 조사로 우선 검증할 수 있다. 주최·파트너 담당자 확인이나 임직원 인터뷰는 향후 공식 경로가 제공될 때만 사용한다. |
| 검증 필요 | 향후 제공 데이터·API·샌드박스·브랜드 자산·담당자/고객 리서치 범위, 제공 시점, 담당 법인, 사용권·동의·평가 조건. Q-04·Q-05·Q-15·Q-16·Q-17·Q-18·Q-19·Q-20·Q-21·Q-22·Q-23 참조. |
| 신뢰도 | 높음과 `확인된 문제` 판정은 2026-08-04 현재의 미제공·무접근 프로젝트 조건과 그로 인한 현재 검증 제약에만 적용한다. MCM 내부 데이터 준비도와 향후 provisioning은 확인 불가. |
