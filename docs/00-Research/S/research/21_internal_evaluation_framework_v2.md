# Internal Evaluation Framework v2

> 작성일: 2026-08-04. 1차 자료: 공식 Q&A (`15`). 원칙: `18`. 탐색 기준: `20`.
>
> **⚠️ 공식 심사표는 수정하지 않는다.** 공식 배점은 문제 정의 25 / 실현 가능성 20 / 시장성 15 / UI·UX 10 / 전달력 10 / 트랙 적합성 20 [OFF-003·OFF-020·OFF-022, **Fact**]이며 그대로 유효하다.
>
> **이 문서는 우리 팀 내부 판단 도구다.** 공식 심사표가 "무엇을 평가받는가"라면, 이 프레임워크는 **"공식 심사표에서 좋은 점수를 받으려면 Q&A 기준으로 무엇을 갖춰야 하는가"**를 정의한다.
>
> **근거 수준:** `Fact` = MCM 직접 답변 또는 공식 가이드. `Inference` = 복수 답변 연결. `Hypothesis` = 미검증 추정.

### E-01. Customer Engagement — 14점 ⭐ 최고 배점

| 항목 | 내용 |
| --- | --- |
| **평가 질문** | 이 문제를 풀면 브랜드가 고객에게 **실제로 더 가까이** 가는가? |
| **높은 점수 (12~14)** | 문제 해결이 곧 브랜드-고객 관계의 형성·심화. 고객이 브랜드가 자신을 안다고 느끼는 지점이 명확함 |
| **중간 (7~11)** | 관계에 간접 기여하나 주된 효과는 다른 곳(편의·정보) |
| **낮은 점수 (0~6)** | 문제를 풀어도 브랜드-고객 거리가 그대로. 도구만 하나 늘어남 |
| **필요한 근거** | 문제 지점과 Engagement 결핍 사이의 **인과 설명** |
| **Q&A 근거** | **"Customer Engagement, 즉, 고객과 더 가까이 다가가는 것입니다. ... 맞춤형 케어가 많이 부족합니다."** [QA-4-3] |
| **분류** | **Fact**(MCM이 최우선 문제로 지목) + **Inference**(배점 설계) |
