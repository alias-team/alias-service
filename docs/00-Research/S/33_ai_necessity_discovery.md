## 질문 1. 모든 고객에게 같은 경험을 보여주면 실패하는 지점은 어디인가?

| 지점 | 왜 실패하는가 | 근거 |
| --- | --- | --- |
| **다음 목적지가 다르다** | 방콕으로 가는 사람과 헬싱키로 가는 사람에게 같은 제품 이야기를 하면 둘 다 자기 이야기가 아니다. 기후·일정·이동 방식이 전부 다르다 | 면세의 정의상 **Fact** / 실패한다는 것은 **Inference** |
| **가용 시간이 다르다** | 탑승 40분 전과 3시간 전에게 같은 깊이의 경험을 주면 한쪽은 놓치고 한쪽은 지루하다 | 충동 구매 33%로 증가 [A/B급] |
| **브랜드를 아는 정도가 다르다** | Gen Z 67%가 처음 사는 제품을 산다 — 같은 진열이 누군가에겐 첫 소개, 누군가에겐 반복 | E3 **Fact** |
| **개입을 원하는 정도가 다르다** | 76%가 상호작용이 결정에 영향을 줬다고 답하지만, 나머지는 방해로 느낄 수 있다 | E4 **Fact** / 방해 인식은 **Hypothesis** |

**핵심(Inference·높음):** 실패하는 지점은 **"고객의 상황이 다른데 매장은 하나"**인 모든 자리다. 그중 면세에만 있는 변수는 **다음 목적지**와 **탑승까지 남은 시간**이다.

## 질문 2. 고객마다 답이 달라야 하는 것은 무엇인가?

| 답이 달라야 하는 것 | 왜 | Non-AI 가능성 |
| --- | --- | --- |
| **이 제품이 당신의 다음 3일에서 어떻게 쓰이는가** | 목적지·기간·목적이 다르다 | 🟢 **불가** — 전 세계 취항지를 사전 제작할 수 없다 |
| **지금 당신에게 필요한 정보의 양** | 가용 시간이 다르다 | 🟡 부분 — 5분/15분 동선으로 근사 가능 |
| **당신을 멈추게 할 한 가지** | 관심 축이 다르다 | 🟢 **불가** — 모두에게 같은 것은 정의상 개별 개입이 아니다 |
| 브랜드의 어느 이야기부터 | 사전 지식이 다르다 | 🔴 가능 — 두 층위 콘텐츠 병렬 배치로 커버 [`32` D-09 탈락] |
| 선물인가 자기용인가 | 목적이 다르다 | 🔴 가능 — 직원이 묻는다 [`32` D-05 탈락] |

**핵심(Inference·높음):** **답이 달라야 하면서 동시에 Non-AI로 만들 수 없는 것은 두 가지뿐이다** — `다음 여정에서의 제품 의미`와 `이 사람을 멈추게 할 한 가지`.

## 질문 3. 고객이 직접 말하지 않은 것을 이해해야 하는 순간은 어디인가?

**이 질문이 P2-05에서 가장 중요하다.** 면세 매장에서 고객의 **44~46%는 직원과 상호작용하지 않는다** [E5, Fact]. 즉 **절반 가까이가 아무것도 말하지 않는다.**

| 말하지 않은 것 | 관측 가능한 신호 | 개인 식별 필요? |
| --- | --- | --- |
| 관심 있는 제품군 | 어느 매대 앞에 멈췄는가, 무엇을 집어 들었는가 | ❌ 불필요 (익명 세션) |
| 관심의 강도 | 얼마나 오래 머물렀는가, 몇 번 되돌아왔는가 | ❌ 불필요 |
| 가용 시간 | 이동 속도, 짐 구성, 게이트까지 거리 | ❌ 불필요 |
| 다음 목적지 | 탑승권·게이트 (고객 자발 제공 시) | ❌ 불필요 (목적지는 개인 식별자가 아니다) |
| 여행의 성격 | 짐 구성, 동행 여부, 시간대 | ❌ 불필요 |

**핵심(Inference·중간~높음):** 면세 매장에서 고객이 남기는 것은 **말이 아니라 행동과 맥락**이다. 그리고 **그 신호들은 개인을 식별하지 않고도 읽을 수 있다.** 이는 MCM의 통과 조건 [QA-5-1·QA-5-3, A급 공식]과 충돌하지 않는다.

**⚠️ 단, 관측 수단이 카메라라면 Luxury Guardrail G-06(고객을 측정 대상으로 취급 금지)·"감시받는다는 느낌" 기준과 충돌한다.** 이 경계는 Solution 단계에서 반드시 다뤄야 한다.

## 질문 4. 짧은 시간 안에 여러 신호를 동시에 해석해야 하는 순간은 어디인가?

| 순간 | 동시에 읽어야 하는 신호 | 신호 수 |
| --- | --- | --- |
| **고객이 제품을 집어 든 순간** | 어떤 제품 · 얼마나 오래 · 앞서 무엇을 봤는가 · 다음 목적지 · 남은 시간 · 동행 여부 | 6개 이상 |
| **고객이 매장을 지나치려는 순간** | 이동 방향 · 속도 · 시선이 머문 지점 · 체류 시간 · 게이트 방향 | 5개 이상 |
| **고객이 결제를 망설이는 순간** | 제품 · 가격 반응 · 대안 비교 여부 · 남은 시간 | 4개 이상 |

**핵심(Inference·높음):** 면세의 시간 압박은 **판단의 여유가 없다는 뜻**이다. 사람이 6개 신호를 몇 초 안에 통합하려면 숙련된 어드바이저여야 하고, 그런 어드바이저는 **동시에 한 명만 상대할 수 있다.**

## 질문 5. 직원 한 명이 모든 고객에게 할 수 없지만 AI라면 동시에 할 수 있는 것은 무엇인가?

**이것이 AI 필연성의 가장 강한 논거다.**

| 축 | 사람의 한계 | AI가 가능한 것 |
| --- | --- | --- |
| **동시성** | 한 번에 한 명(잘해야 두 명) | 매장 안 모든 익명 세션을 동시에 |
| **전지성** | 전 세계 목적지·기후·일정 지식을 다 가질 수 없다 | 목적지 × 제품 조합을 즉시 |
| **비접촉성** | 말을 걸어야 시작된다 | 말을 걸지 않은 고객에게도 |
| **무피로성** | 피크 시간대에 응대 품질이 떨어진다 | 일정 |

**MCM이 이 논거를 스스로 제시했다** — **"너무나 많은 시장, 매년 수많은 고객을 상대하다 보니 럭셔리 브랜드에서 신경을 많이 써야 할 맞춤형 케어가 많이 부족합니다. 따라서 AI를..."** [QA-4-3, **A급 공식**]. `따라서`가 규모 → AI의 인과를 명시한다.

**⚠️ 그러나 주의:** 동시성만으로는 부족하다. **동시에 무엇을 하는가**가 Non-AI로 가능하면(예: 모두에게 같은 콘텐츠 표시) AI 필연성은 없다. **동시성 × 개별성**이 함께 있어야 한다(Inference).

## 질문 6. Rule-based로는 경우의 수가 너무 많아지는 판단은 무엇인가?

| 판단 | 조합 규모 추정 | Rule 가능성 |
| --- | --- | --- |
| **목적지 × 제품 × 기간 × 목적** | 취항지 수백 × 제품 수십 × 기간 3~4 × 목적 3~4 = **수만~수십만 조합** | 🟢 **불가** |
| **행동 신호 조합 → 진입점** | 신호 6개 × 각 3~5단계 = **수백~수천 상태**, 그리고 상태마다 다른 출력 | 🟢 **불가** |
| 남은 시간 → 콘텐츠 길이 | 3~4구간 | 🔴 가능 |
| 국적 → 언어 | 언어 수만큼 | 🔴 가능 |
| 제품 → 관련 상품 | 카탈로그 크기 | 🔴 가능 (기존 추천 로직) |

**핵심(Inference·높음):** 조합 폭발이 실제로 일어나는 것은 **`목적지 관련 판단`과 `행동 신호 통합 판단`** 두 가지뿐이다. 나머지는 Rule로 충분하며, 이는 `32` Step 2의 탈락 판정과 일치한다.

## 질문 7. AI가 고객보다 먼저 행동해야 가치가 생기는 순간은 무엇인가?

MCM은 **"AI를 고객이 원하는 것을 한발 앞서 제시하고"** [QA-4-3, A급 공식], **"말을 걸어주거나, 경험을 자연스럽게 유도하는 장치"** [QA-3-3, A급 공식]라고 답했다.

| 순간 | 왜 먼저여야 하는가 | 고객이 먼저 움직이길 기다리면 |
| --- | --- | --- |
| **매장을 지나치려는 순간** | 지나치면 끝이다. 요청을 기다릴 시간이 없다 | 44~46%가 그대로 나간다 [E5, Fact] |
| **제품을 집어 들었다 내려놓는 순간** | 이 몇 초가 결정 지점이다 | 이탈이 이미 일어난 뒤다 |
| **탑승 시각이 다가오는 순간** | 시간이 줄면 결정이 아니라 포기가 된다 | 결정 기회 자체가 사라진다 |

**⚠️ 그러나 Luxury Guardrail과 긴장한다.** MCM은 **"고객이 생경하게 여기는 기술 중심 장치는 지양"** [QA-3-3, A급 공식]하라고 했고, Step 9 체크리스트는 **"AI가 과도하게 말을 걸거나 방해하지 않는가"**, **"감시받는다는 느낌을 주지 않는가"**를 요구한다.

**즉 선제성은 필요하지만 그 표현이 `개입`이 아니라 `준비된 상태`여야 한다**(Inference·중간). 이 경계가 Solution 설계의 핵심 제약이다.

## 종합 — AI 필연성이 성립하는 자리

### 7개 질문의 수렴

| 질문 | 수렴 지점 |
| --- | --- |
| Q1 같은 경험이 실패하는 곳 | 다음 목적지 · 가용 시간 |
| Q2 답이 달라야 하는 것 | **다음 여정에서의 제품 의미** · **이 사람을 멈추게 할 한 가지** |
| Q3 말하지 않은 것 | 44~46%가 아무 말도 하지 않는다 |
| Q4 동시 해석 | 6개 이상 신호를 몇 초 안에 |
| Q5 사람이 못 하는 것 | **동시성 · 전지성 · 비접촉성** |
| Q6 Rule 불가 | **목적지 조합** · **행동 신호 조합** |
| Q7 먼저 행동 | 지나치려는 순간 · 내려놓는 순간 |

### 🟢 AI 필연성이 성립하는 두 자리 (Inference·높음)

**자리 1 — 고객의 다음 여정과 제품 사이의 판단**
```
근거: Q1(목적지 차이) + Q2(사전 제작 불가) + Q5(전지성) + Q6(조합 폭발)
면세 특수성: 면세 매장은 고객의 다음 목적지를 알 수 있는 유일한 리테일 접점이다
MCM 특수성: 1976년 여행 헤리티지 · Made for Movement · Global Nomad [A급 공식]
Non-AI 불가 이유: 취항지 수백 × 제품 × 기간 × 목적을 사전 제작할 수 없고,
                직원이 전 세계 목적지를 알 수 없다
```

**자리 2 — 말하지 않는 고객에 대한 개별 개입 판단**
```
근거: Q3(44~46% 무접촉) + Q4(6개 신호) + Q5(동시성·비접촉성) + Q6(신호 조합) + Q7(선제)
수치 근거: 상호작용률 54~56%, 개입받은 사람의 76%가 결정에 영향 인정 [E4·E5, Fact]
Non-AI 불가 이유: 직원은 정의상 이 고객에게 도달하지 못했고,
                콘텐츠·사이니지는 모두에게 같으므로 개별 개입이 아니다
```

### 🔴 AI 필연성이 성립하지 않는 자리

| 자리 | 왜 |
| --- | --- |
| 브랜드 스토리 전달 | 콘텐츠·공간 설계로 잘 풀린다. 산업 표준 대응 [B급]. **AI 도슨트로 회귀** |
| 다국어 응대 | 번역으로 해결 |
| 구매 목적 파악 | 직원이 묻는다 |
| 상품 추천 | 기존 추천 로직으로 충분 |
| 사전 지식 대응 | 두 층위 콘텐츠 병렬 배치 |

## 이 문서의 한계

1. **조합 규모 추정(Q6)은 이 조사의 산정**이며 실측이 아니다.
2. **행동 신호의 관측 가능성(Q3)은 기술적 검토 없이 개념 수준**이다. 실제 면세 매장에서 어떤 신호를 어떻게 얻을지는 미검증이다.
3. **"44~46%가 전환하지 않는다"는 직접 교차 데이터가 아니다.** 상호작용률과 영향 인정률은 별도 수치이며, 비접촉 고객의 전환율을 직접 측정한 자료는 확보하지 못했다(`Inference`).
4. **MCM 자체 면세 데이터가 전무하다.**
5. **Solution을 만들지 않았다.**
