# [Challenge 02 · 인터랙티브 리테일] Rabot 브라스플레이트 인텔리전스

**관점**: 직원 · **점수**: AI저지 88 / 휴먼저지 8

**한 줄 pitch**: "50년간 잠들어 있던 시리얼 넘버가, 이제 말을 합니다."

---

## 문제

MCM은 전 제품에 브라스플레이트+고유 시리얼을 부착하지만, DPP(NFC)와 달리 이 시리얼은 어떤 디지털 경험과도 연결되지 않은 채 방치돼 있다. 그 결과 두 가지 문제가 겹친다.

1. **응대 품질이 직원 개인 역량에 좌우됨** — MCM HAUS 청담 외 대부분 매장은 도슨트 없이 신입·베테랑 직원의 제품 설명 편차가 큼
2. **정품 불안** — 명품 위조시장 연 5,000억달러+ 규모, 비세토스처럼 유명한 모노그램일수록 위조 타깃이 되기 쉬움

왜 지금인가 — 2026년은 MCM 50주년 "SMART Luxury"(디지털 융합) 캠페인 해. 50년간 아무 말 없던 브라스플레이트에 처음 디지털 지능을 연결하는 것만큼 이 슬로건에 맞는 소재가 없음.

## 해결

직원이 제품의 브라스플레이트 QR(시리얼)을 스캔 → Rabot이 그 자리에서 30초짜리 세일즈 내레이션(소재·헤리티지·50주년 스토리 + 정품확인 배지)을 생성 → 직원이 자기 말투로 고객에게 전달.

**고객은 화면을 전혀 보지 않는다** — "이 직원이 이 제품을 다 아는 것처럼 이야기하네"라는 체감만 남는다.

## 기술 아키텍처 (간단히)

Next.js + Supabase + OpenAI API (기존 팀 스택 그대로 재사용, 신규 외부 API 없음). QR 스캔은 표준 JS 라이브러리 사용(OCR 같은 실패율 높은 기술 지양). MCM 공식 페이지의 실제 제품 정보를 시딩 데이터로 사용하고, 스토리는 매번 LLM이 즉석 생성.

## 왜 안 겹치나

| 비교 대상 | 차이 |
|---|---|
| Zegna X | 고객 데이터 기반 관계 인사이트 vs 이건 제품 데이터 기반 스토리 — 축이 다름 |
| Aura(블록체인 정품인증) | 새 인프라 필요 없음, 기존 시리얼 DB+LLM일 뿐. 정품확인은 부가기능, 핵심은 스토리텔링 |
| Longchamp×YOOBIC | 사전 교육 콘텐츠(오프라인형) vs 이건 판매 현장 실시간 생성(현장형) |
| Rabot 고객기억 브리핑(확정4) | 고객 데이터(재방문자만) vs 제품 데이터(초회 방문객도 항상 작동) — 트리거 자체가 다름 |
